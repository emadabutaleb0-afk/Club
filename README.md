# منصة مركز التنمية الشبابية بالتجمع الأول (Smart Youth Club Platform)

منظومة إدارية ومالية ورقمية سحابية متكاملة مدعومة بالذكاء الاصطناعي، مصممة لإدارة وتشغيل مراكز التنمية الشبابية والأندية الرياضية الحديثة بأعلى معايير الحوكمة والتحول الرقمي.

---

## 🌟 أبرز مميزات المنظومة (Key Features)

1. **الواجهة الرسمية والمركز الإعلامي (Portal & Media Center)**:
   - نافذة إعلامية تفاعلية تعكس الأنشطة والمجهودات الإنشائية والتنظيمية بالمركز.
   - استعراض شامل للأكاديميات الرياضية والأنشطة المعتمدة (السباحة الأولمبية، التنس والبادل، كرة القدم، الكاراتيه، تنس الطاولة، اللياقة البدنية والجمباز).
   - جدول البطولات والفعاليات ومعرض الصور والفيديوهات وأخبار المركز.

2. **منظومة الذكاء الاصطناعي المتطورة (AI Suite)**:
   - **المساعد الذكي للمركز (AI Assistant 24/7)**: يجيب على جميع استفسارات الأعضاء وأولياء الأمور فورياً باللغة العربية.
   - **المطابق الرياضي الذكي (AI Sport Matcher)**: يساعد أولياء الأمور في تحديد الرياضة والمسار الأنسب لأطفالهم بناءً على السن والميول والقدرات البدنية.
   - **تنظيم المواعيد والأوقات**: خوارزميات جدولة تمنع تضارب الحصص التدريبية وحجوزات الملاعب بنسبة 100%.
   - **زيادة الإنجاز ومضاعفة الإنتاجية**: أتمتة حصر الحضور، إصدار الفواتير فورياً، وإلغاء النزاعات الناتجة عن التدخل البشري والورقي.

3. **حجز الملاعب والمرافق التفاعلي (Interactive Facilities Booking)**:
   - عرض فوري للملاعب والمنشآت المتاحة، اختيار الفترات الزمنية بالساعة، والدفع الإلكتروني المباشر.

4. **إدارة شؤون الأعضاء والاشتراكات (Smart CRM & Membership)**:
   - بطاقة عضوية رقمية تدعم رمز الاستجابة السريع (QR Code) لتسهيل الدخول عبر البوابات الذكية.
   - تجديد الاشتراكات السنوية وحساب رسوم التجديد وغرامات التأخير تلقائياً.

5. **مركز تقارير ذكاء الأعمال ودعم القرار (BI & Analytics)**:
   - لوحات تحكم بيانية حية لقياس التدفقات النقدية، الإيرادات الشهرية، معدلات إشغال الملاعب، ونمو قاعدة الأعضاء.
   - تصدير فوري للتقارير الرسمية بصيغ Excel و PDF لاعتمادها بمحاضر مجلس الإدارة.

6. **البوابة المالية والتحصيل الرقمي (Payment Gateway)**:
   - تكامل مع بوابات الدفع الإلكتروني (البطاقات البنكية، المحافظ الإلكترونية، فوري).
   - إصدار إيصالات دفع وفواتير إلكترونية موثقة تمنع التسرب المالي بنسبة 100%.

## 🛠️ البنية التقنية (Architecture & Tech Stack)

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Recharts, Framer Motion, Lucide Icons, Zustand.
- **Backend**: Node.js, Express, TypeScript, SQLite / Prisma ORM, JWT Authentication.
- **Shared**: حزم TypeScript مشتركة للأنماط والتحقق من صحة البيانات.
- **Design System**: دعم الوضع الليلي والفاتح (Dark/Light mode) وثنائية اللغة (عربي / إنجليزي) مع دعم كامل لاتجاه RTL.

## 🚀 طريقة التشغيل السريع (Quick Start)

### المتطلبات الأساسية
- Node.js (v18+)
- npm أو pnpm

### تثبيت الاعتماديات
```bash
# تثبيت حزم المشروع بالكامل
npm install
```

### تشغيل البيئة التطويرية
```bash
# تشغيل الخادم الخلفي (Backend Server)
cd backend
npm run dev

# تشغيل واجهة المستخدم (Web Frontend) في نافذة منفصلة
cd ../web
npm run dev
```

- الواجهة الأمامية: `http://localhost:5173`
- الخادم الخلفي: `http://localhost:3000`
